# Port session lifecycle + self-improvement bridge

> **Status:** ship (2026-07-21) — landed; astrix adoption pending a product call

## Context

RDS (roblox-development-studio) ADR-0010 activated a session-lifecycle loop entirely inside its own `.claude/`: a `/start` command (Wake dangling-triage · Orient one-shot brief · Open an "engram" session carrying `last-active`+`kos` tags and a `First-Principles Candidates` export-queue section), a `/end` that closes the open session to a terminal state, and `proseStatusEnforcement: error` so status flips are guard-enforced paired edits. This pipeline ports that loop into canonical Project-System as framework-native behavior across both command surfaces (`.claude/` framework-variant and `templates/consumer/.claude/` consumer-variant), requiring **zero schema change** (engram state lives entirely in the freeform `tags` map), and adds a propose-only **self-improvement bridge** (`/reflect`): a periodic review that mines the accumulated session ledger to propose command/instruction/skill/config improvements. One merged effort: the bridge depends on the port's First-Principles scaffold default and hooks a cadence nudge into `/start`'s Wake pass.

**Ships (port):** `/start` both variants; session-close folded natively into `/end` both variants (de-delimited); `STANDARD_PRESET` + dogfood-config defaults for `last-active`/`kos` tags and the First-Principles scaffold section; a `BUILTIN_HINTS` entry in `new-entity.mjs`; an `init-config` self-test case proving the defaults; schema-doc coverage; a documented parseable **consumer-extension delimiter grammar** (re-vendor-safe consumer-local additions — a hard prerequisite of the bridge's proposals).

**Ships (bridge):** `/reflect` as a **consumer-template command only**, plus a threshold-gated nudge sub-step in `/start` Wake (both variants). `/reflect` mines closed engrams, emits a propose-only checklist, and records each review as a `report` entity that doubles as the cursor for the next run.

**Explicitly does NOT ship:** any schema change or new primitive field (drift check fails on new fields — engram state is tags-only); any third hook ("two hooks, no more"); a command-file drift axis in `check-consumer-drift.mjs` (no `// FUTURE` note either); a `bridgeReview.cadence` config key (N is a prose constant); a framework-variant `/reflect` (canonical's three sessions predate engrams — nothing to mine); a `kos.lintAgainst` mirror (the roster table in the command IS the vocabulary); retro-fitting legacy tag-less sessions (asset-studio's 9 born-`completed` retros stay untouched).

*Extended after ship (2026-07-22):* the scheduled-routines lane (ADR 0017) extended the block below in six places — the First-Principles hint (a `routine` candidate home); `/reflect`'s pass list (a fifth **Routine candidates** pass) and its `placement` list (a fifth value, `routine`); `/end`'s Capture pass (a third top-level bullet, **Automation candidates**, between *The planning ledger* and *Close the open session*); `/start`'s Orient pass 3 (a `cadence`-tagged-workflow line); and a `cadence` tag registered in `STANDARD_PRESET` plus both live configs, with a new spec §4b paragraph. Distinct from the `bridgeReview.cadence` config key the block above still correctly disclaims. The shipped command files are current; this is the ship-day snapshot.

**Resolved design decisions (implementing session: honor these):**
- **Two-variant discipline** — author both variants from the RDS source via marker-anchored transforms (never line-number-keyed). Framework variant: `node tools/…` paths, literal kinds, error-strict claims. Consumer variant: `node .project-system/tools/…`, kind-neutral ("handoff-shaped kind — standard: session"), **warn-honest** guard wording (two real consumers run `warn`: "where `proseStatusEnforcement` is `error` a half-flip is guard-blocked; at `warn` it is flagged, not blocked — keep the flip atomic regardless").
- **Preset stays `warn`** — tightening to `error` is a documented per-consumer adoption step, not a preset change. Canonical's dogfood config already runs `error` and is where the paired flip is proven end-to-end.
- **FPC hint mechanism (verified)** — `new-entity.mjs buildContent` resolves `ctx.sectionHints[s] ?? BUILTIN_HINTS[s] ?? "<…>"` over `scaffoldSections`, so a `BUILTIN_HINTS` entry makes the hint universal: `"First-Principles Candidates": "- <one-sentence insight> → <candidate home: decision · brain capture · memory · none yet>"`. The `<…>` placeholders are load-bearing: the bridge discriminates authored candidates from the untouched hint by the presence of `<`.
- **Scaffold mechanics (preserve verbatim)** — two separate commands, `date +%Y-%m-%dT%H:%M` first, then `new-entity.mjs <kind> "<goal>" --status active --tag last-active=<literal>`; **never inline `$(date …)`** (command substitution defeats the permission-prefix rule). `kos` is added **via Edit, not `--tag`** (the scaffolder emits an unquoted inline map; a comma-bearing value breaks the flow map). `tags` stays a single-line flow map; quote comma-bearing values; status flips are one Edit spanning frontmatter `status:`/`updated:` through the prose `> **Status:** …` line.
- **`blocked` deconfliction** — dangling = `{planned, active}` only. `blocked`-with-real-Blockers is parked-but-alive: surfaced by Wake as a live thread, a legitimate `/end` terminal close, and **excluded from bridge mining**. The bridge mines `{completed, shelved}` engrams only — settled work.
- **Nudge mechanics** — appended to Wake, both variants: grep closed engrams (`^status: (completed|shelved)` ∩ `^tags:.*last-active`); find the newest bridge-review report by lexical sort of `_project/reports/*` matching `^title: "Bridge review`, read its `## Window covered` `cursor:` line (none → epoch); count closed engrams with `last-active` strictly greater; ≥ N (**3**, per the *Resolved at ship* note) → one nudge line; below → silent.
- **`/reflect` roster & mining** — engrams = files with `^tags:.*last-active` (auto-excludes legacy retros and `/new session`-created files — intentional); mine: (B) drain First-Principles sections **bounded to the next `## ` heading**, keep `- … → … none yet` lines without `<`; (C) `kos` reach-frequency **within the review window only** (majority slug → standing-context candidate); (D) Decisions themes + Handoff/Blockers pain (agent judgment, no engine); (E) read the actual `.claude/` surface before proposing. Output: propose-only checklist, each item with one `placement` field: `upstream` (hand-off note to this repo — a consumer never edits canonical), `consumer-extension` (delimited block, applied on approval), `config` (consumer's own, applied on approval), `memory` (auto, reported).
- **Cursor state** — one `report` per review: `new-entity.mjs report "Bridge review — <startISO>..<endISO>" --slug bridge-review-<HHMM>` (date-slug kind; `--slug` disambiguates same-day), then Edit in `## Window covered` (first line `cursor: <max last-active mined, or run timestamp>` — machine-authoritative; the title is never parsed), `## Findings`, `## Proposals` **with disposition** (accepted/deferred/rejected so rejected ideas aren't re-proposed), and `links` to mined sessions. No report-shaped kind → `/reflect` recommends adding one and does not run.
- **Bounds & degradation** — default window is cursor-bounded; `--since <date>` overrides; `--all` caps at the 20 most-recent closed engrams with a skip warning. Ladder: no session kind → "bridge inactive"; 0 files → "insufficient ledger"; only tag-less legacy → filter returns 0 → "insufficient ledger"; 1–2 engrams → nudge silent, manual run warns low-signal.
- **Delimiter grammar** — opener `<!-- consumer-extension: <slug> · <note> -->`, closer `<!-- /consumer-extension: <slug> -->`; plus `<!-- consumer-specific: … -->` pair. Must land in the port phase (the bridge's `consumer-extension` proposals slot into it).
- **Governance** — this pipeline is the build record (slug filename, no serial collision). If an ADR is wanted: **one** decision 0017 for the merged design (ceiling today is 0016 — do not mint two 0017s). The bridge capability may optionally be a `feature` entity (`--tag tier=optional`), distinct from this pipeline.

## Exit criteria

- `node tools/init-config.mjs --self-test` and `node tools/new-entity.mjs --self-test` pass, including the NEW preset case (session scaffold contains First-Principles in position; both tags present).
- `node tools/validate.mjs` clean at canonical root under `error` enforcement; `node tools/render-hub.mjs --check` not stale after config+command edits.
- Dogfood in canonical: `/start "<goal>"` scaffolds the engram (two commands, no `$()`; `kos` Edited in quoted); `/end` closes it via one spanning Edit; a lone frontmatter flip is guard-BLOCKED (canonical is `error`). Canonical's three pre-engram sessions stay invisible to Wake and bridge.
- Fixture gate: re-vendored `soul-steel-demo` validates 0-error; `/start`→`/end` cycle works; `/reflect` reports "insufficient ledger" gracefully.
- Bridge cursor round-trip: after one `/reflect` writes `bridge-review-<HHMM>` with a `## Window covered` `cursor:` line, the next `/start` nudge computes from that cursor; same-day second review does not collide.
- `--all` cap: on a synthetic ledger > 20 closed engrams, `/reflect --all` caps at 20 with a skip warning.
- Per-consumer: `validate.mjs` clean after each adoption; asset-studio's legacy sessions remain invisible to Wake and bridge.

**Open questions for the implementing session:** (1) astrix adoption — session-shaped kind now vs inert commands (product call). (2) Cadence N — default 5 is untested; consider N=3 to exercise the first loop sooner. (3) The bridge matches the literal `## First-Principles Candidates` heading — fixed framework convention (current plan) vs a config key (new surface); nothing else depends on the choice.

*Resolved at ship (2026-07-21):* (2) N = **3** — every real ledger is small today; at 5 the first loop wouldn't fire for weeks, and an early nudge costs one line. (3) **Fixed framework convention** — the heading is already framework-blessed via `STANDARD_PRESET`/`BUILTIN_HINTS`; a config key would be new surface with one reader. (1) **Still open** — surfaced to Nicholas, deliberately not guessed; the reviewers' low-signal-band overlap fix (reflect warns at 1–2, nudge fires at 3) rode along with the N=3 choice.
